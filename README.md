# 📝 To-Do List em Python

Aplicação de lista de tarefas desenvolvida em **Python**, com interface gráfica e armazenamento das tarefas em arquivo de texto.

Este projeto foi desenvolvido com o objetivo de praticar conceitos de **programação em Python**, organização de código e construção de uma aplicação simples com interface gráfica.

## 🚀 Funcionalidades

* ➕ Adicionar tarefas
* 📋 Visualizar tarefas cadastradas
* ✏️ Gerenciar tarefas pela interface gráfica
* 💾 Armazenar as tarefas em arquivo `.txt`
* 🖥️ Utilizar uma interface gráfica para interação com o usuário

## 🛠️ Tecnologias utilizadas

* **Python**
* **Tkinter** — criação da interface gráfica
* **Arquivo TXT** — armazenamento das tarefas

## 📂 Estrutura do projeto

```text
todolist-python/
├── app_to_do_imperativo.py
├── todolist_imperativo.py
├── tarefas.txt
└── README.md
```

### `app_to_do_imperativo.py`

Responsável pela **interface gráfica** da aplicação.

### `todolist_imperativo.py`

Contém a lógica responsável pelo **gerenciamento das tarefas**.

### `tarefas.txt`

Arquivo utilizado para **armazenar as tarefas cadastradas**.

## ▶️ Como executar

1. Tenha o **Python** instalado.
2. Clone ou baixe este repositório.
3. Abra a pasta do projeto no **PyCharm** ou em outra IDE.
4. Execute o arquivo:

```text
app_to_do_imperativo.py
```

A interface gráfica será iniciada e você poderá gerenciar suas tarefas.

Projeto desenvolvido para colocar em prática conhecimentos de **Python e programação imperativa**, trabalhando conceitos como funções, variáveis, manipulação de arquivos, organização de código e interface gráfica.
